# Plan 05-01: Grounded RAG Pipeline, Chat Router, Session Management and Leak Test

## Objective
Implement Phase 5 deliverables:
1. `backend/app/adapters/pii/regex_redactor.py`: PII redaction adapter for student IDs, emails, phone numbers.
2. `backend/app/adapters/llm/gemini_llm.py`: Gemini adapter implementing `LLMPort`.
3. `backend/app/application/use_cases/answer_question.py`: Orchestrates PII redaction, query rewriting, hybrid retrieval, LLM invocation, citation verification, abstention gating, and persistence.
4. `backend/app/adapters/persistence/chat_repo.py`: Chat repository implementing `ChatRepoPort`.
5. `backend/app/adapters/api/routers/chat.py`: Endpoints for `POST /api/chat`, `GET /api/chat/sessions`, `GET /api/chat/sessions/{id}`, `POST /api/chat/messages/{id}/feedback`.
6. Wire chat router into `backend/app/main.py`.
7. `backend/tests/leak_test.py`: Automated security leak test suite.
8. `backend/tests/unit/test_phase5_rag.py`: Unit tests for PII redaction, grounded prompt contract, citation checker, follow-ups, and chat API.
