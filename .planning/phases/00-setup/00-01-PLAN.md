# Plan 00-01: Scaffolding, Domain Entities, Application Ports and Settings

## Objective
Implement Phase 0 deliverables:
1. Root environment files: `CLAUDE.md`, `.env.example`, `docker-compose.yml`, `Makefile`, `.gitignore`, `README.md`.
2. Backend structure:
   - `backend/requirements.txt` with pinned stable dependencies.
   - `backend/app/domain/`: `entities.py`, `access_policy.py`, `citation_rules.py`, `errors.py`.
   - `backend/app/application/`: `ports.py`, `pipeline/`.
   - `backend/app/composition/`: `settings.py`, `container.py`.
   - `backend/app/adapters/api/`: `error_handlers.py`, `dependencies.py`.
   - `backend/app/adapters/persistence/`: `database.py`, `models.py`.
   - `backend/app/adapters/llm/`: `fake_llm.py`.
   - `backend/app/main.py`: FastAPI app with `/api/health` and central error handling.
   - `backend/tests/`: unit tests for domain entities, access policy, and health endpoint.
3. Frontend skeleton:
   - `frontend/package.json`, `frontend/tsconfig.json`, `frontend/vite.config.ts`, `frontend/tailwind.config.js`, basic index.html and app layout.

## Tasks
- [ ] Task 1: Create root environment and configuration files (`.gitignore`, `.env.example`, `docker-compose.yml`, `Makefile`, `CLAUDE.md`).
- [ ] Task 2: Create `backend/requirements.txt` and domain core (`entities.py`, `access_policy.py`, `citation_rules.py`, `errors.py`).
- [ ] Task 3: Create application ports (`ports.py`) and composition settings (`settings.py`, `container.py`).
- [ ] Task 4: Create persistence layer (`database.py`, `models.py`) and FastAPI entrypoint (`main.py`, routers, error handlers).
- [ ] Task 5: Create frontend scaffolding (`package.json`, configs, basic App component).
- [ ] Task 6: Create initial unit tests and verify test suite passes.
