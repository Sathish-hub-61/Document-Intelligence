# Plan 02-01: Document Ingestion, Extraction and Chunking Pipeline

## Objective
Implement Phase 2 deliverables:
1. `backend/app/adapters/storage/local_files.py`: Local secure file storage adapter with magic byte validation and SHA-256 computation.
2. `backend/app/adapters/extraction/pymupdf_extractor.py`: PDF page-aware text and heading extractor with `needs_ocr` detection.
3. `backend/app/adapters/extraction/docx_extractor.py`: DOCX paragraph and heading extractor.
4. `backend/app/application/use_cases/chunker.py`: Section-aware chunking preserving token counts, pages, and headings.
5. `backend/app/application/use_cases/ingest_document.py`: Ingestion orchestrator managing job transitions.
6. `backend/app/adapters/persistence/repositories.py`: Expand `SqlAlchemyDocumentRepo` to support documents, versions, chunks, and jobs.
7. `backend/app/adapters/api/routers/documents.py`: Document upload (202), listing, job status, chunk fetching, and file download endpoints.
8. `backend/tests/unit/test_phase2_ingestion.py`: Unit and integration tests covering extraction, chunking, and upload.

## Tasks
- [ ] Task 1: Implement file storage and validation adapter (`local_files.py`).
- [ ] Task 2: Implement PDF (PyMuPDF) and DOCX extractors.
- [ ] Task 3: Implement section-aware chunking utility.
- [ ] Task 4: Complete `SqlAlchemyDocumentRepo` persistence implementation.
- [ ] Task 5: Implement document ingestion use case and background runner.
- [ ] Task 6: Implement document router (`/api/documents`, `/api/chunks`, `/api/files`) and wire into `main.py`.
