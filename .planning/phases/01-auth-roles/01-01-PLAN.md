# Plan 01-01: User Persistence, Security Token Service, Auth Routes and Role Guards

## Objective
Implement Phase 1 deliverables:
1. `backend/app/adapters/security/password.py`: Argon2 password hashing and verification.
2. `backend/app/adapters/security/jwt_service.py`: PyJWT token generation and verification.
3. `backend/app/adapters/persistence/repositories.py`: `SqlAlchemyUserRepo` implementing `UserRepoPort`.
4. `backend/app/adapters/api/dependencies.py`: `get_current_user`, `require_role`.
5. `backend/app/adapters/api/routers/auth.py`: `/api/auth/login`, `/api/auth/register`, `/api/auth/me`.
6. `backend/app/adapters/persistence/seed.py`: seed script populating 4 role accounts.
7. `backend/tests/unit/test_phase1_auth.py`: unit and integration tests verifying all auth criteria.

## Tasks
- [ ] Task 1: Implement Argon2 hashing and JWT service.
- [ ] Task 2: Implement User repository with database query logic.
- [ ] Task 3: Implement auth dependencies (`get_current_user`, `require_role`).
- [ ] Task 4: Implement auth router (`login`, `register`, `me`) and wire into `main.py`.
- [ ] Task 5: Implement database seeding function and CLI entrypoint.
- [ ] Task 6: Write and verify unit tests for auth and role guards.
